# Code of Conduct

## Our standard

Contributors must communicate respectfully, welcome technical disagreement, avoid harassment, protect private information, and distinguish verified engineering evidence from claims or marketing language.

Unacceptable behavior includes personal attacks, discriminatory language, threats, publishing private information, deliberate security harm, and misrepresenting test or safety results.

## Scope

This standard applies in repository discussions, issues, pull requests, reviews, and community spaces where someone represents HarborVision Twin.

## Enforcement

Report conduct concerns privately through the repository owner’s GitHub profile. Maintainers may edit or remove content, close discussions, reject contributions, temporarily restrict participation, or permanently ban participants when necessary. Reports will be handled as confidentially as practical.

## Attribution

This policy is inspired by the Contributor Covenant and adapted for this engineering project.
